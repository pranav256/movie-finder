# Movie Finder

An asynchronous film search portal connecting to the OMDb / TMDB REST API.

## Features

- **Debounced Search:** Instant title query handling with client-side input debouncing.
- **Detailed Metadata:** Displays release year, genre, director, plot summary, and IMDb ratings.
- **Poster Grid:** Responsive poster grid layout with fallback placeholders for missing artwork.

## Tech Stack

- Vanilla JavaScript (Fetch API)
- OMDb / TMDB REST API
- HTML5 & CSS3

## Usage

Open `index.html` in any web browser and type a movie title to search.
